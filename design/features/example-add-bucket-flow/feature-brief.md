# Example — Add a bucket

> **Example only.** This brief demonstrates a multi-screen package
> (design/README.md). The "Add bucket" screen already exists in the app, so the
> approved screens document it as built; nothing here is to be implemented.

## Problem

A user who wants to cap their spending in a category has to find where to do
it, pick the category, set a monthly amount and understand what went wrong when
the form is rejected.

## Goal

Adding a bucket takes one short form, and a rejected submit says exactly what to
fix.

## Constraints

- Follow design/system/README.md and use only its tokens.
- Only categories that have no bucket yet can be picked.
- Every visible string needs English and Spanish.
- One gold primary button per screen.
